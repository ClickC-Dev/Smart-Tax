Solid, accessible button for actions across the Smart Tax dashboard and marketing site.

```jsx
<Button variant="primary" size="md">Continuar</Button>
<Button variant="gold">Enviar declaração</Button>
<Button variant="secondary">Cancelar</Button>
```

Variants: `primary` (navy), `gold` (bronze accent, for the single highest-priority action per view), `secondary` (outlined), `ghost` (text-only), `outlineInverse` (for use on dark/navy backgrounds). Sizes: `sm` / `md` / `lg`. Supports a leading or trailing `icon` node and `disabled`.
